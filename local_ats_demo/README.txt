Local ATS Demo Adapter - Operational Instructions
==================================================

1. Place authorized text-based PDF (.pdf) or native DOCX (.docx) resumes into the local_ats_demo/inbox directory.
2. Log into the platform and open the Recruiter portal (Candidates -> Upload Resume -> Import from ATS / File).
3. Select "Local ATS Demo" as the ATS Connector.
4. Select a destination job from the job selector.
5. Click "Scan Folder" to run a safe dry-run preview.
6. Review the itemized preview and confirm valid imports.
7. Important: Never commit candidate resumes or personal data to git.
